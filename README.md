# Iris Flower Clustering Project

## 📌 Project Overview

This project applies unsupervised machine learning to the Iris dataset using K-Means clustering. PCA is also used to reduce the dataset dimensions and visualize the clusters.

## 🎯 Objectives

- Apply K-Means clustering with k = 3
- Visualize the generated clusters
- Compare predicted clusters with true labels
- Apply PCA for dimensionality reduction
- Visualize the data in 2D

## 📊 Dataset

The Iris dataset contains 150 flower samples with four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The three flower classes are:

- Setosa
- Versicolor
- Virginica

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- K-Means Clustering
- PCA

## 🔬 Methodology

1. Load the Iris dataset
2. Explore the dataset
3. Standardize the features
4. Apply K-Means clustering with 3 clusters
5. Visualize the clusters
6. Compare clusters with actual labels
7. Apply PCA
8. Visualize the PCA results

## 📈 Results

K-Means successfully groups the Iris samples into three clusters. PCA reduces the four-dimensional feature space to two dimensions, making the clusters easier to visualize.

## ✅ Conclusion

The project demonstrates how unsupervised learning can be used to identify patterns in the Iris dataset. K-Means clustering provides meaningful groups, while PCA helps visualize the data in a simpler two-dimensional form.
